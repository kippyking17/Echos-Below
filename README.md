# Echos Below

ECHOS BELOW — v3.3.0 / build 20261017.24

PLAY: https://kippyking17.github.io/Echos-Below/

SOLO WITH FRIENDS: the original game, now with private parties for up to four logged-in players. Same maps, story, equipment, inventory, markets, Graces, controls and boss fights. Host starts or continues a solo journey, then M > Multiplayer > Create room. Share the code, everyone chooses Ready, and the host begins. Friends join the host's saved location. Boss HP and ACT progress, puzzle completion and roaming enemies are shared; each player controls their own movement, health and equipment. Original boss stats are preserved.

Chat works in the lobby and Party panel, supports Enter, keeps typing focus during updates, and preserves unsent messages after connection errors. Names, levels and HP appear with friends. Existing login-only access, four-player limit and one-minute chat bans remain active.

Refresh everyone to v3.3.0 and leave/recreate rooms from older versions. Guests keep their solo saves; party progress is cached separately and restored when rejoining the same code. Host progress uses the normal save. Use the same browser/profile for saves.

WINDOWS: extract the whole ZIP, then open EchosBelow-AutoUpdate.exe. The existing stable launcher opens the latest live game and future versions. Internet/browser required. Creator publishing is optional and off by default; Git for Windows and authorized GitHub sign-in are required.

IPHONE / IPAD: Safari > Share > Add to Home Screen. Landscape touch controls match the original game. To replace an old icon, remove and re-add the shortcut without clearing website data.

The game folder is deployable as a website root. The current live backend is activated. New installations: follow MULTIPLAYER-SETUP.txt. No secret keys belong in game files.
