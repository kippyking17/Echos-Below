ECHOES BELOW v0.8.1 — Fix online signups and logins

WHY IT DID NOT WORK:
The supplied cloud-config.json had empty strings. The game was never connected to your Supabase project.

OWNER SETUP:
1. Go to your own Supabase project > Project Settings > API Keys (or Connect) to get Project URL and PUBLIC publishable key (sb_publishable_...) or legacy anon key (eyJ...).
2. Open cloud-config.json in Notepad; fill in supabaseUrl and supabaseAnonKey. Keep the quotes. NEVER use your secret or service_role key in this file.
3. Open Supabase SQL Editor; run supabase-setup.sql to create game_saves and game_admins and row-level security policies. Review the SQL before running.
4. Supabase Authentication > Providers > Email (or Sign In / Providers > Email): keep Email sign-ins enabled and disable Confirm email for THIS username-only prototype. Username-only dummy email aliases cannot receive emails.
5. Upload the entire echoes_below folder including cloud-config.json to the EXISTING Netlify site > Deploys. Ctrl+Shift+R to refresh.
6. Check ECHOES BELOW v0.8.1 in the top-left. Enter a username and 6+ character password, click Create account. Supabase Authentication > Users should now show a user. Log in as needed.
7. To grant admin: you must create and verify YOUR KingKippy account first, then use the trusted SQL Editor to assign its UID to public.game_admins. See the last lines of supabase-setup.sql. Merely knowing the username must not grant admin.

WARNING: This dummy-email username-only login is a game prototype, not production-quality account security. It does not support email confirmations or password recovery, and requires appropriate anti-abuse controls before public launch. For a secure public game, implement a server-managed username-to-account mapping and real account recovery.

If it says LOGIN NOT CONNECTED, config is still missing. If it says Login connection failed, verify the URL and public key. If it says Email not confirmed, disable Confirm email as described above. If it says Invalid login credentials, ensure the account was created in this specific Supabase project.
